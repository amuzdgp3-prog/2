# Общий протокол памяти

Этот блок устанавливается в пользовательский `~/.codex/AGENTS.md` после существующих предпочтений.
Оригинал в Git нужен для восстановления; файл проекта не заменяет пользовательские инструкции.
Локальный реестр `~/.codex/memory/PROJECTS.md` содержит только пути к точкам входа проектов.

## Память и экономия контекста

- В новом чате сначала прочитай инструкции рабочей папки и короткую точку входа памяти проекта
  (обычно `docs/memory/START.md` и `CURRENT.md`, если они существуют). Если проект неясен,
  посмотри локальный реестр `~/.codex/memory/PROJECTS.md`; не загружай память других проектов.
- Сначала найди нужный модуль по карте/индексу, затем читай выбранную функцию и её потребителей.
  Используй адресные поиски и диапазоны. Не читай целиком большие журналы решений, исходники,
  логи и старые чаты, когда достаточно краткой выдачи. Ограничивай вывод, сужай обрезанные запросы.
- Долговременные решения сохраняй рядом с кодом: правило, причина, область, источник,
  что уточнено/отменено, реализация, проверка. История чата и сжатый контекст — вспомогательные
  источники; нельзя обещать полную память всех прошлых чатов.
- После существенного этапа длинной задачи, перед передачей/сжатием и при завершении обновляй
  краткое состояние проекта: цель, сделано, следующий шаг, препятствия, ветка/коммит, проверки.
  Не стирай незавершённые параллельные задачи. Завершённое сворачивай, не накапливай дневник.
- Отделяй подтверждённое от предположений. Старые проверки, локальное применение, push и прод
  различай явно. При конфликте проверь область более позднего решения и текущий код.
- При изменении структуры/контракта актуализируй карту и ссылки памяти в той же задаче.
  Не копируй код в документацию; ссылайся на реальные файлы/символы. Указывай пределы проверки.
- Не сохраняй в памяти секреты, пользовательские данные, сырые выгрузки/чаты и скрытые рассуждения.
  Не меняй внутренние базы/историю Codex ради памяти. Общие правила — в пользовательских
  инструкциях, факты проекта — в его Git, локальные пути/окружение — в локальном реестре.
