# Память проекта: короткий вход

Это переносимая память Apixspb Machine Monitor, репозиторий `amuzdgp3-prog/2`.
Она работает без истории чата и без отдельного сервера. Не читай все документы подряд.

1. Прочитай применимые `AGENTS.md` и [CURRENT.md](CURRENT.md).
2. Найди тему: `node scripts/memory.mjs topic "клешня"` (или `topic` для списка).
3. Команда покажет точки входа, связанные решения и подходящие тесты. Читай только нужный слой.
4. Если имени файла/функции нет в карте: `node scripts/memory.mjs find "ownerMonthRoi"`.
5. Перед изменением: `node scripts/memory.mjs outline api/src/domain/ownerMonthRoi.ts` —
   определения с актуальными строками, прямые локальные импорты и импортирующие файлы.
   Затем прочитай нужный диапазон кода и проверь непосредственных потребителей.
6. История: `node scripts/memory.mjs search "ROI"`, затем `node scripts/memory.mjs decision 091`.
   Не загружай весь `DECISIONS.md`. Для старых решений выводятся известные уточнения/замены.

## Где какая истина

| Сведения | Источник |
|---|---|
| Намерение и разрешения | Последние явные указания владельца + применимые инструкции |
| Действующие бизнес-правила | Решения с учётом области и более поздних уточнений; подтверждать кодом/проверкой |
| Реализация и зависимости | Исходники, миграции, актуальная выдача `find` / `outline` |
| Состояние задачи | [CURRENT.md](CURRENT.md), незавершённые пункты с доказательствами |
| Причины и история | Конкретные разделы `DECISIONS.md`, Git; чат — вспомогательный архив |
| Окружение и доступ | Сначала `LOCAL-README.md`, если есть; README относится к описанной в нём среде |

При противоречии назови его, выясни область изменения и проверь факты. Более поздняя запись
не отменяет старую целиком автоматически. Отсутствие записи в списке замен не означает,
что старое решение действует: список известных замен неполон.

## Экономия контекста

- Старт: инструкции + CURRENT + одна тема. Не читать весь журнал решений, большие роуты и логи.
- `find` индексирует пути, объявления и строки маршрутов; `outline` строит связи статических
  относительных импортов. Это навигация, не полный AST/call graph и не доказательство отсутствия связей.
- Локальный скрипт обрабатывает только `api/src`, `api/tests`, `web/src`, два конфига сборки
  и три собственных скрипта `scripts/memory*.mjs`.
  Содержимое БД, фото, `.env`, `ACCESS.txt`, дампы, `dist` и `node_modules` не индексируются.
- В ответ модели попадает ограниченная выдача: до 8 находок, 24 объявлений и 12 связей,
  не более 8 000 символов за команду. Сужай запрос, если выдача обрезана.
- Нулевой результат поиска не доказывает отсутствие функциональности: попробуй имя на другом
  языке, путь/символ и адресный `rg`. Для динамических зависимостей проверь регистрацию маршрутов,
  SQL, очереди, конфигурацию и соответствующие тесты.
