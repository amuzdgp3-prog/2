# Макет «Админ → Аппараты»

05.11.2026. Статус: подготовлен для согласования по DECISION-095; не применён к приложению.
Источник: запрос владельца на дизайн вкладки администратора и её карточек, уточнённый
скриншотом `/admin`. Область — `web/src/screens/admin/machines/MachinesTab.tsx`,
а не утверждённая ранее карточка истории `History.tsx` (DECISION-099).

Открыть `admin-machines-review.html` в браузере. Файл автономный, без зависимостей,
внешних запросов и реальных данных. Демонстрационные действия ничего не сохраняют.

Предложение: тёплая палитра текущего интерфейса, компактные строки парка,
поиск и фильтры, отдельные списки рабочих/списанных аппаратов. Раскрытие строки
показывает единый список параметров: название, значение и действие в строке.
По уточнению владельца убраны внутренние блоки и дублирующее размещение;
действие переноса находится внизу карточки. Операции открывают диалог;
списание вынесено вниз и требует отдельного подтверждения. Выбор наклеек — отдельный режим.
Сводка и фильтр наличия терминала — предложения интерфейса, не новые правила учёта.

При реализации сохранить все действующие формы и права, классификаторы, аренду,
явный пересчёт истории, установку аппарата и печать наклеек. Их полное поведение
не воспроизведено в демонстрационных диалогах. Общее меню приложения и админ-вкладки
не являются частью этой задачи. Реализацию начинать после согласования макета.

Проверка: headless Chrome/Playwright, ширины 1440/768/390/320 без горизонтального
переполнения; поиск, пустое состояние, фильтры, списанные, раскрытие, диалоги,
Escape, опция терминала при переносе, выбор наклеек и запрет выбора без адреса;
нет ошибок JavaScript. PNG 1440 и 390 просмотрены визуально. Локальный сайт, API,
пользовательская БД и прод не менялись. Интерактивные проверки относятся к макету.
