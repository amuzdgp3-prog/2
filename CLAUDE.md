# CLAUDE.md

Рабочие инструкции для Claude Code по репозиторию `2.apixspb.ru` (Apixspb Machine Monitor).

Описание системы и эксплуатация — в [README.md](README.md).
Принятые ранее решения и их обоснование — в [DECISIONS.md](DECISIONS.md); перед тем как
менять уже реализованное поведение, проверь, нет ли по нему записи `DECISION-NNN`.

## Правила

- [Правила модульности и безопасных изменений](.claude/rules/modularity.md) — планирование
  перед многомодульными изменениями, работа по одному слою за раз, отдельный коммит на
  каждый законченный шаг, подтверждение перед сменой контракта.

## Git

Отдельный коммит на каждый логически законченный шаг. Push в GitHub (origin) после такого
коммита делается без отдельного разрешения на каждый раз, когда это полезно — владелец подтвердил
лично 15.09.2026. Форс-пуш и перезапись истории по-прежнему требуют явного согласия отдельно.

## Прод

С 16.09.2026 прод `2.apixspb.ru` — не эта машина разработки, а отдельный выделенный сервер
(IP: 185.147.82.69), см. DECISION-077. Любое действие на этом сервере — тот же уровень
осторожности, что и правила модульности для этого репозитория: подтверждение перед разрушающими
операциями, никаких широких изменений без предварительного плана.
