# CLAUDE.md

Рабочие инструкции для Claude Code по репозиторию `2.apixspb.ru` (Apixspb Machine Monitor).

Описание системы и эксплуатация — в [README.md](README.md).
Принятые ранее решения и их обоснование — в [DECISIONS.md](DECISIONS.md); перед тем как
менять уже реализованное поведение, проверь, нет ли по нему записи `DECISION-NNN`.

## Правила

- [Правила модульности и безопасных изменений](.claude/rules/modularity.md) — планирование
  перед многомодульными изменениями, работа по одному слою за раз, отдельный коммит на
  каждый законченный шаг, подтверждение перед сменой контракта.

## Git

Коммиты делаются только локально. Не пушить в GitHub или другой remote без явного
указания владельца.
